
No test framework is configured.

## Environment

Copy `.env.example` to `.env` and set `VITE_PB_URL` to the PocketBase instance URL before running.

## Architecture

**Riddly** is a mobile-first swipeable card app for browsing riddles and jokes. The stack is React 19 + TypeScript, TanStack Router (file-based), Tailwind CSS v4, shadcn/ui (radix-nova style, Tabler icons), motion/react for drag animations, and PocketBase as the backend.

### Routing

TanStack Router with file-based routing under `src/routes/`. The route tree (`src/routeTree.gen.ts`) is auto-generated by the Vite plugin — never edit it manually. Routes:

- `__root.tsx` — shared layout (background, backdrop blur)
- `index.tsx` — home/category selection
- `riddles.tsx` / `jokes.tsx` — card browsing pages

### Data layer

`src/config/pb.ts` initializes the PocketBase client from `VITE_PB_URL`. All data access goes through service files:

- `src/api/humour-card.service.ts` — base service wrapping the `humour_cards` PocketBase collection. Only exposes `getAllRandom`. Expands the `category` relation and flattens `expand.category` into a top-level `category` field via `flattenCategory`.
- `src/api/riddle.service.ts` / `joke.service.ts` — call `getAllRandom` with a PocketBase filter string. Riddles filter on `type = 'riddle' && deleted = false`; jokes filter on `type = 'joke'`.

The shared DTO is `GetAllHumourCardDto` (`src/api/humour-card.ts`): `{ id, title, hint, answer, category: { label, color } }`. `hint` is conceptually riddle-only and `answer` may be empty for some cards — components guard with truthiness checks rather than relying on the type.

`ExpandableResult<T>` (`src/types/expandable-result.ts`) types the raw PocketBase record before flattening.

Cards are shuffled client-side with Fisher-Yates (`src/lib/array.utils.ts`) — note `getAllRandom` shuffles, and the riddle/joke services shuffle the result again.

### Card component

`src/components/card-stack.tsx` is the core UI component. It uses a compound component pattern (`CardStack`, `CardStack.Item`, `CardStack.Front`, `CardStack.Back`) with React Context to share swipe state. motion/react handles drag; a swipe is triggered at **150px displacement or 500px/s velocity**. Cards behind the active one scale down and darken. Card flip uses CSS `rotate-y-180` with `backface-hidden`.

### Styling conventions

- Tailwind CSS v4 with OKLCH-based CSS variables for theming
- `cn()` from `src/lib/utils.ts` (tailwind-merge + clsx) for class merging
- `font-heading` class uses the Outfit Variable font; body uses Geist Variable
- shadcn/ui components live in `src/components/ui/`

### Code quality

- ESLint enforces **kebab-case** for file names and folder names under `src/`. TanStack Router route files are exempt.
- TypeScript strict mode is on; unused variables and parameters are errors.
- React Compiler (Babel plugin) handles automatic memoization — avoid manual `useMemo`/`useCallback` unless there is a specific reason.
